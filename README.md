# Autonomous AI Assistant

Полноценное локальное desktop-приложение автономного ИИ-помощника с темной темой, чатом, долговременной памятью, обучением через интернет, автономным режимом, журналом действий, рабочей папкой файлов и настройками нагрузки.

## Возможности

- **Чат:** принимает обычный текст, хранит историю диалога, обращается к релевантной памяти и отвечает более живым разговорным стилем.
- **Языковые модели:** в настройках можно включить локальную Ollama (`llama3.2`, `mistral`, `qwen` и т.п.) или `transformers`; если модель недоступна, работает встроенный разговорный режим без дополнительных зависимостей.
- **Долговременная память:** все диалоги, знания, задачи, самоанализ и файлы сохраняются в SQLite и переживают перезапуск приложения.
- **Самостоятельное обучение:** кнопка «Начать обучение» ищет источники в интернете, читает страницы, выделяет ключевые знания, подключает LLM-наставника (Ollama/transformers/fallback) и сохраняет резюме в память и файл Markdown.
- **Колонка прогресса обучения:** правая панель показывает тему, процент выполнения и статус каждого этапа обучения, чтобы было видно, как модель продвигается по задаче.
- **Автономный режим:** кнопка «Автономный режим» запускает фоновый цикл обучения по новым и связанным темам, используя прошлые знания, задачи и отчеты самоанализа. Процесс можно остановить в любой момент.
- **Лог действий:** каждое системное событие автоматически пишется в `actions.log` и отображается в интерфейсе.
- **Работа с файлами:** поддерживаются `txt`, `md`, `json`, `csv`, `html`, `py`, `js`, `css`, `cpp`, `java`; файлы можно создавать, открывать, редактировать и сохранять.
- **Работа с кодом:** помощник создает стартовые программы и мини-проекты на Python, JavaScript, HTML/CSS, C++ и Java.
- **Самоанализ и самоулучшение:** после задач сохраняется отчет о результате; режим самомодификации создает безопасные планы и примеры изменений в `workspace/self_mods`, а критические файлы приложения не меняются без проверки человеком.
- **Настройки ресурсов:** низкая, средняя, высокая и максимальная нагрузка меняют число источников и темп автономной работы.

## Запуск

Требуется Python 3.10+ с установленным Tkinter. В большинстве установок Python на Windows и macOS Tkinter уже включен; на Linux может потребоваться пакет `python3-tk`.

```bash
python run.py
```

Также можно запускать готовыми файлами из корня проекта:

- Windows: `run.bat`;
- Linux/macOS: `./run.sh`;
- универсально: `python -m autonomous_ai_assistant`.

Данные приложения по умолчанию хранятся в `~/.autonomous_ai_assistant`:

- `memory.sqlite3` — долговременная память;
- `actions.log` — журнал действий;
- `workspace/` — созданные заметки, код и проекты;
- `settings.json` — настройки приложения.

Для тестового запуска с отдельной папкой данных:

```bash
AUTONOMOUS_AI_DATA=/tmp/my-ai-data python -m autonomous_ai_assistant
```


## Прогресс, LLM-наставник и самомодификация

- Правая колонка **«Прогресс обучения»** показывает последние этапы: постановка темы, поиск, чтение источников, выделение знаний, помощь LLM и сохранение результата.
- Настройка **«LLM помогает обучению»** включает этап, где локальная Ollama, transformers или встроенный fallback превращает найденные материалы в учебный план, контрольные вопросы и практические шаги.
- Автономное обучение теперь опирается на прошлый опыт: релевантные знания, завершенные задачи, отчеты самоанализа и предложения улучшений.
- Настройка **«Самомодификация»** имеет режимы:
  - `workspace` — по запросу создает план самоулучшения в рабочей папке;
  - `autonomous_workspace` — дополнительно создает такие планы после автономного обучения;
  - `off` — отключает функцию.

Самомодификация намеренно безопасная: приложение генерирует планы и кодовые идеи в `workspace/self_mods`, чтобы их можно было проверить перед переносом в исходники.

## Локальная языковая модель

По умолчанию включен режим `auto`: приложение сначала пробует локальную Ollama по адресу `http://127.0.0.1:11434`, а если она недоступна, использует встроенный живой режим.

Пример с Ollama:

```bash
ollama pull llama3.2
ollama serve
```

Затем в приложении откройте **Настройки** → **Языковая модель** = `ollama`, **Модель** = `llama3.2`. Для полностью автономного встроенного режима выберите `off`.

`transformers` остается опциональным backend: установите пакет и укажите локальную/доступную модель в настройках, если хотите экспериментировать с базовыми Hugging Face моделями.

## Ограничения реализации

Приложение не тренирует нейросеть с нуля. Вместо этого реализован практичный рабочий вариант автономного помощника: накопление знаний, полнотекстовый поиск по памяти, чтение интернет-источников, резюмирование, ведение заметок, создание файлов и отчетов. Для генерации «как в ChatGPT» можно подключить локальную LLM через Ollama/transformers; без нее ответы формируются встроенным разговорным fallback-режимом.
